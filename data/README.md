# 합격 후기 수집 시트

팀원이 직접 입력하는 데이터는 코드와 떨어진 이 폴더에 있어요. 서비스의 경향 분석(`/trends`)이 여기 있는 데이터를 읽어요.

| 파일 | 무엇 | 어떻게 보나 |
|---|---|---|
| [**수집시트.xlsx**](수집시트.xlsx) | **입력용 엑셀.** '작성 방법' · '수집' · '코드북' 탭 | 파일을 열고 오른쪽 위 **Download raw file** 버튼으로 받아 엑셀에서 열기 |
| [**curated.csv**](curated.csv) | 앱이 실제로 읽는 데이터 ('수집' 탭을 CSV로 저장한 것) | GitHub에서 바로 **표로** 보여요. 검색·정렬도 돼요 |

## 가장 쉬운 방법: 앱의 '엑셀 관리' (관리자)
GitHub 없이 앱에서 끝나요. 관리자 계정으로 로그인 → 왼쪽 메뉴 **엑셀 관리 (관리자)** (`/admin/sheet`)
1. **엑셀 받기**: 지금 시트 + 앱에서 검수·코딩한 후기가 모두 들어 있는 수집시트를 받아요.
2. '수집' 탭의 노란 칸을 고치고 그대로 저장해요.
3. **올리고 미리보기** → 추가·변경·삭제와 오류를 확인 → **적용하기**
- 올린 시트는 버전으로 쌓이고 '이걸로 되돌리기'로 언제든 되돌려요. 이 파일(data/curated.csv)은 바꾸지 않아요.
- 팀원에게 관리자 권한을 주려면 Vercel 환경 변수 `ADMIN_LOGIN_IDS`에 그 사람의 아이디를 쉼표로 더해요.

## GitHub으로 올리는 순서
1. [수집시트.xlsx](수집시트.xlsx)를 받아 엑셀에서 열어요. 먼저 **'작성 방법'** 탭을 읽어 주세요.
2. **'수집'** 탭의 **노란 칸만** 입력해요. 회색 칸(출처 표기 · 중복 체크 · 총점)은 수식이라 자동으로 채워져요.
   - 2행(L-001)이 작성 예시예요.
   - 분야 · 결과 단계 · 신뢰도 · 검수 상태 같은 칸은 목록에서 골라요.
   - E1~E8 점수는 **'코드북'** 탭 기준으로 0 · 1 · 2점. 후기에 없으면 0점이에요.
3. 다 쓰면 '수집' 탭을 **CSV UTF-8**로 저장해 `data/curated.csv`를 바꾸고 PR을 올려요.
   (엑셀: 파일 → 다른 이름으로 저장 → 형식 `CSV UTF-8(쉼표로 분리)`)

### AI로 먼저 점수 매기기 (추천)
앱의 **후기 분석 (팀)** 화면(`/reviews`)에 후기 링크와 본문을 넣으면 AI가 코드북으로 점수 초안과 근거를 만들어요. 사람이 확인해서 '검수 완료'로 저장한 뒤 **CSV 내보내기**를 누르면, '수집' 탭과 같은 열 순서의 CSV가 받아져요. 그대로 시트 아래에 붙여넣으면 돼요.

### 구글 시트로 같이 쓰고 싶다면
수집시트.xlsx를 구글 드라이브에 올려 구글 시트로 연 뒤, 아래 주소를 `apps/web/.env.local`(배포는 Vercel 환경 변수)의 `TRENDS_CSV_URL`에 넣으면 앱이 저장소 CSV 대신 그 시트를 바로 읽어요.

```
https://docs.google.com/spreadsheets/d/<시트ID>/gviz/tq?tqx=out:csv&sheet=수집
```

## 꼭 지킬 것
- **원문을 붙여넣지 않아요.** 요약 · 팁 · 면접 질문은 모두 내 말로 2문장 이내. 후기 게시물의 저작권은 작성자에게 있어요.
- **출처는 반드시.** URL · 사이트 이름 · 제목을 채우면 출처 표기가 자동으로 만들어지고, 화면과 발표에 함께 나가요.
- **크롤링하지 않아요.** 사이트 약관 때문에 자동 수집 프로그램은 쓰지 않고, 직접 열어 본 후기만 넣어요.
- **검수 완료**는 다른 팀원이 원문과 대조해 확인한 행에만 붙여요.

## 열 설명 (짧게)
| 열 | 설명 |
|---|---|
| ID | `L-001`처럼 출처 앞 글자 + 번호 |
| 출처 유형 · 플랫폼/사이트명 · 게시물 제목 · URL · 게시일 · 확인일 | 출처 표기에 쓰여요. 게시일을 모르면 `확인 필요` |
| 주최사 · 활동명·기수 · 분야 · 활동 유형 · 결과 단계 | 어떤 활동의 후기인지 |
| 사전미션 · 면접 · 신규 계정으로 지원 · 팔로워 수 언급 | 후기에 나온 대로 (`Y` / `N` / `언급 없음`) |
| E1~E8 | 합격 요인 점수 0~2 (코드북) |
| 언급된 콘텐츠 포맷 · 합격 요인 키워드 · 전형 키워드 | 키워드는 `#성과수치 #포폴압축`처럼 #태그를 띄어 써요 |
| 면접 질문 요약 · 핵심 팁 | 내 말로 |
| 신뢰도 | 상: 본인 합격 후기 + 구체적 / 중 / 하: 전해 들은 말 |
| 검수 상태 | `원문 재확인 필요` 또는 `검수 완료` |
